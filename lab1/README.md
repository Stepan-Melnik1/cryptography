# 🔐 Лабораторная работа: Инструментарий криптографических алгоритмов (C++)

Модульное консольное приложение на языке C++, реализующее классические шифры, арифметику в конечных полях ($GF(2^8)$), методы модульной арифметики, вычисление дискретных логарифмов и битовое шифрование файлов.

---

## 📁 Архитектура проекта и описание модулей

Проект разделен на логические модули, каждый из которых отвечает за свой раздел криптографии:

1. **`main.cpp`** — Главный файл (точка входа). Отвечает за разбор аргументов командной строки (`argc`, `argv`), проверку ошибок и вызов нужных функций в зависимости от выбранного флага.
2. **`vars.h` / `vars.cpp`** — Модуль конфигурации. Содержит базовые алфавиты различной длины (`letters`, `letters2`, `letters3`), используемые в классических шифрах.
3. **`ciphers.h` / `ciphers.cpp`** — Классические шифры (Разделы 1–2):
   * Шифр Цезаря (`CSR`).
   * Шифр Цезаря с кодовым словом / смешанным алфавитом (`CSK`).
   * Шифр Виженера с поддержкой расширенных таблиц (`VGN`).
4. **`galois.h` / `galois.cpp`** — Поле Галуа $GF(2^8)$ (Раздел 3.1):
   * Крестьянское умножение по стандарту AES (`gf_mult_peasant`).
   * Операции с многочленами и предвычисление таблиц логарифмов/антилогарифмов для быстрого умножения.
5. **`expmod.h` / `expmod.cpp`** — Модулярное возведение в степень $b^e \pmod m$ (Раздел 3.2):
   * Двоичный метод справа налево (RTL).
   * Двоичный метод слева направо (LTR).
   * Лестница Монтгомери (Montgomery Ladder) для защиты от атак по времени.
6. **`invmod.h` / `invmod.cpp`** — Обратный элемент по модулю $a^{-1} \pmod m$ (Раздел 3.3):
   * Расширенный алгоритм Евклида (EEA).
   * Метод на базе Малой теоремы Ферма (для простых модулей).
7. **`logdis.h` / `logdis.cpp`** — Дискретный логарифм $g^x \equiv h \pmod p$ (Раздел 3.4):
   * Полный перебор (Brute Force).
   * Алгоритм «шаг младенца — шаг великана» (BSGS).
8. **`vgb.h` / `vgb.cpp`** — Битовый Виженер и файловое шифрование (Раздел 4):
   * Побитовые операции (`XOR`, `AND`, `OR`) над байтами сообщений и ключей.
   * Очистка непечатаемых символов (`VGB_exclud`) и шифрование содержимого произвольных файлов.

---

## ⚙️ Сборка проекта

Для компиляции всех модулей в единый исполняемый файл `crypto` выполни в терминале следующую команду:

```bash
g++ main.cpp ciphers.cpp vars.cpp galois.cpp expmod.cpp invmod.cpp logdis.cpp vgb.cpp -o crypto
```

## 🚀 Примеры запуска и использование

Программа управляется с помощью консольных ключей (флагов). Ниже приведены примеры запуска для каждого функционального блока:

### 1. Классические шифры (Виженер)
Зашифровать сообщение с помощью ключа:
```bash
./crypto -Evgn "Hello World 2026!" "SecretKey"
```
Расшифровать сообщение:
```bash
./crypto -Dvgn "ЗашифрованныйТекст" "SecretKey"
```

### 2. Поле Галуа $GF(2^8)$
Запустить проверку умножения на эталонном примере из стандарта AES (`0x57 * 0x83`):
```bash
./crypto -gf
```

### 3. Модулярное возведение в степень
Вычисление выражения $15^{4947} \pmod{31}$ методом RTL (`rlbe`):
```bash
./crypto -ME rlbe 15 4947 31
```
*(Доступные методы: `rlbe`, `lrbe`, `ml`, `swe`)*

### 4. Обратный элемент по модулю
Найти обратный элемент для $7 \pmod{11}$ с помощью расширенного алгоритма Евклида (`eea`):
```bash
./crypto -MI eea 7 11
```
*(Доступные методы: `eea`, `ferma`, `gcd`)*

### 5. Дискретный логарифм
Решить уравнение $2^x \equiv 22 \pmod{29}$ методом BSGS:
```bash
./crypto -DL bsgs 2 22 29
```
*(Доступные методы: `br`, `bsgs`, `pollard`, `ph`, `ic`)*

### 6. Битовый Виженер и шифрование файлов
Зашифровать текст побитовым XOR (`-Evgb`):
```bash
./crypto -Evgb "Hello World" "Key"
```
Зашифровать содержимое текстового файла (`data.txt`):
```bash
./crypto -Fvgb data.txt "Key"
```
## 📚 Подробное описание функций и принципов работы

### 1. Классические шифры (`ciphers.cpp`)

#### `CSR_encrypt` / `CSR_decrypt` (Шифр Цезаря)
- **Принцип работы:** Моноалфавитная подстановка с фиксированным или заданным сдвигом ($k$). Каждый символ входящего сообщения ищется в массиве алфавита (`letters`). Его индекс смещается на величину ключа по модулю длины алфавита.   
- **Формула шифрования:** $E(m_i) = (m_i + k) \pmod{26}$
- **Формула расшифрования:** $D(m_i) = (m_i - k + 26) \pmod{26}$

#### `CSK_keygen` (Генерация ключа для Цезаря с ключом)
- **Принцип работы:** Создает уникальный смешанный алфавит. Ключевое слово ставится в самое начало, после него дописывается стандартный алфавит (`letters2`), после чего из получившейся строки удаляются все дубликаты символов. Это повышает стойкость к перебору (мощность ключа возрастает от 26 до $26!$).   

#### `CSK_encrypt` / `CSK_decrypt` (Цезарь с кодовым словом)
- **Принцип работы:** Замена символов стандартного алфавита на соответствующие символы сгенерированного с помощью `CSK_keygen` уникального алфавита-ключа. При шифровании буква из `letters2` заменяется на букву из `key` по тому же индексу. При расшифровании — наоборот.   

#### `VGN_encrypt` / `VGN_decrypt` (Шифр Виженера)
- **Принцип работы:** Полиалфавитный шифр. Использует ключевое слово, длина которого меньше или равна сообщению. Ключ циклически повторяется с помощью операции взятия остатка по индексу (`i % key_len`). Каждый символ сообщения складывается по модулю с соответствующим символом ключа.   
- **Формула:** $E(m_i) = (m_i + k_i) \pmod{LEN3}$

---

### 2. Поле Галуа $GF(2^8)$ (`galois.cpp`)

#### `gf_mult_peasant` (Крестьянское умножение)
- **Принцип работы:** Умножение элементов конечного поля без использования таблиц ASCII, с помощью битовых сдвигов (`<<`, `>>`) и операции исключающее ИЛИ (`XOR`). Если при сдвиге числа влево «убегает» старший бит (`0x80`), происходит коррекция (редукция) путем применения неприводимого многочлена стандарта AES (`0x1B`).   

#### `poly_ext_gcd` (Расширенный алгоритм Евклида для многочленов)
- **Принцип работы:** Используется для поиска мультипликативно обратного элемента в поле многочленов. Выполняет последовательное деление многочленов с остатком (на основе XOR-операций), пока остаток не станет равным единице, вычисляя коэффициенты для нахождения обратного.   

#### `precompute_tables` / `gf_mult_table` (Таблицы логарифмов)
- **Принцип работы:** Предварительно рассчитывает таблицы логарифмов и антилогарифмов с использованием генератора поля (`0x03`). Благодаря этому сложное умножение двух элементов в поле сводится к простому сложению их индексов в таблице по модулю 255, что обеспечивает скорость $O(1)$.   

---

### 3. Модулярное возведение в степень (`expmod.cpp`)

#### `mod_pow_rtl` (Двоичное справа налево / RTL)
- **Принцип работы:** Возведение в степень обрабатывает биты показателя $e$ от младшего к старшему (LSB-first). На каждом шаге основание возводится в квадрат, а если текущий бит равен 1, промежуточный результат умножается на текущее основание по модулю $m$.   

#### `mod_pow_ltr` (Двоичное слева направо / LTR)
- **Принцип работы:** Обрабатывает биты показателя от старшего к младшему (MSB-first). На каждой итерации результат возводится в квадрат, и при единичном бите домножается на основание.   

#### `montgomery_ladder` (Лестница Монтгомери)
- **Принцип работы:** Специальный алгоритм возведения в степень за постоянное время (Constant-time execution). Независимо от значения бита (0 или 1), алгоритм выполняет абсолютно одинаковый набор операций умножения над двумя регистрами $R_0$ и $R_1$, что защищает систему от криптографических атак по времени (Timing attacks).   

---

### 4. Обратный элемент по модулю (`invmod.cpp`)

#### `mod_inverse_eea` (Расширенный алгоритм Евклида)
- **Принцип работы:** Находит такое число $t$, что $(b \cdot t) \pmod n \equiv 1$. Алгоритм по шагам вычисляет неполные частные ($q$) и остатки ($r$), параллельно пересчитывая коэффициенты Безу (`t` и `t0`), пока делитель не станет равным 1. Если $\text{НОД}(b, n) \neq 1$, обратного элемента не существует.   

#### `mod_inverse_fermat` (Метод Ферма)
- **Принцип работы:** Использует Малую теорему Ферма для простых модулей $p$. Согласно теореме, обратный элемент вычисляется через быстрое модулярное возведение в степень: $b^{-1} \equiv b^{p-2} \pmod p$.   

---

### 5. Дискретный логарифм (`logdis.cpp`)

#### `brute_force_dlog` (Полный перебор / Brute Force)
- **Принцип работы:** Последовательно перебирает все значения степени $x$ от 0 до заданного лимита. На каждом шаге проверяет условие $g^x \equiv h \pmod p$. Прост в реализации, но имеет сложность $O(p)$, из-за чего неприменим для больших чисел.   

#### `bsgs_dlog` (Шаг младенца — шаг великана / BSGS)
- **Принцип работы:** Алгоритм «встречи посередине» (Meet-in-the-middle) со сложностью $O(\sqrt{p})$. Создает хэш-таблицу для «маленьких шагов» степеней генератора, а затем циклически проверяет «большие шаги» с использованием обратного элемента, что позволяет находить логарифм в разы быстрее полного перебора.   

---

### 6. Битовый Виженер и работа с файлами (`vgb.cpp`)

#### `VGB_encrypt` / `VGB_decrypt` (Битовый Виженер)
- **Принцип работы:** В отличие от классического сдвига по алфавиту, здесь байты исходного сообщения напрямую сравниваются с байтами ключа с помощью битовых операций (`XOR`, `AND`, `OR`). Для симметричных операций (например, XOR) шифрование и расшифрование выполняются одинаково.   

#### `VGB_exclud` (Очистка специальных символов)
- **Принцип работы:** После побитовых манипуляций в тексте могут появляться непечатаемые управляющие символы ASCII (меньше 32 или больше 126), которые ломают вывод в консоль. Функция проверяет каждый байт и заменяет нечитаемые символы на безопасный знак вопроса (`?`).   

#### `VGB_encrypt_file` / `VGB_decrypt_file` (Файловое шифрование)
- **Принцип работы:** Открывает файл на чтение, считывает весь текст в буфер памяти, применяет к нему функцию битового шифрования `VGB_encrypt` с заданным ключом, а затем перезаписывает зашифрованные данные обратно в тот же файл.
